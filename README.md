# EGE History Grader

Проект для проверки заданий ЕГЭ по истории по критериям ФИПИ 2027 года. Модель объясняет выставленный балл и отмечает верные детали ответа ученика.

- [AGENT.md](AGENT.md) — системный промпт проверяющей модели с правилами выставления баллов, разбора ошибок и перепроверки.
- [Поиск по учебникам](%D0%98%D1%81%D1%82%D0%BE%D1%87%D0%BD%D0%B8%D0%BA%D0%B8/README.md) — Поиск нужного параграфа и подключение фрагментов.
- [Спорные ответы](%D0%98%D1%81%D1%82%D0%BE%D1%87%D0%BD%D0%B8%D0%BA%D0%B8/%D0%A1%D0%BF%D0%BE%D1%80%D0%BD%D1%8B%D0%B5%20%D0%BE%D1%82%D0%B2%D0%B5%D1%82%D1%8B%20%E2%80%94%20%D0%BF%D1%80%D0%B8%D0%BC%D0%B5%D1%80%D1%8B%20%D0%A4%D0%98%D0%9F%D0%98%20%D0%B8%20%D0%BF%D0%B5%D1%80%D0%B5%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0.md) — Экспертные примеры, контрольные ответы и правила перепроверки.

Сейчас в репозитории есть инструкции, каталог параграфов и локальный поиск по ним. Для проверки конкретной работы нужны условие задания, критерий и ответ ученика.
