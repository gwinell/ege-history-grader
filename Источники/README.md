# Поиск по параграфам для проверки ЕГЭ-2027

Команда `find` возвращает только название учебника, класс, параграф и наличие текста. Команда `read` выводит один короткий фрагмент. При работе с PDF она передаёт в `pdftotext` только диапазон страниц подключённого параграфа. Размер фрагмента по умолчанию составляет 1800 символов. Число токенов зависит от модели.

Каталог содержит привязки из приложения демоверсии ФИПИ, печатные страницы 35–36. Для № 14 демоверсия указывает на текст самого задания. Ссылки на параграфы для 8-го и 9-го классов относятся к изданиям 2026 года. Для других вариантов подбирайте параграф по теме, используя таблицу 3 и приложение 1 кодификатора.

## В рабочей папке Codex

Используйте обновлённый системный промпт и дайте модели доступ к терминалу в этой рабочей папке. Достаточно Python 3. Для чтения PDF требуется `pdftotext` из Poppler. Текстовые файлы подходят и без Poppler.

```sh
python3 'Источники/поиск.py' find --demo-task 15
python3 'Источники/поиск.py' find --topic 'Ганнибал Пуническая война'
python3 'Источники/поиск.py' read 'w5:43' --query 'Ганнибал Альпы'
```

Для демозадания № 15 первый вызов даёт учебник «История Древнего мира», 5 класс, § 43 «Пунические войны». Последний вызов возвращает встроенную краткую справку о походе Ганнибала по страницам 240–241 издания 2025 года. При подключении своего файла поиск берёт текст из него. Команда `--match 2` выбирает вторую подходящую страницу в PDF, если она найдена.

## Подключение текста

В каталоге есть ссылки на параграфы демоверсии и одна демонстрационная справка. Остальные тексты подключаются отдельно. Если уже есть текст одного параграфа, сохраните его в TXT или Markdown и зарегистрируйте файл. Укажите год и печатные страницы по своему экземпляру.

```sh
python3 'Источники/поиск.py' add 'w5:43' '/путь/к/параграфу-43.txt'
```

Для PDF задайте физические номера страниц в просмотрщике, считая обложку первой страницей. Печатные номера могут отличаться. В примере 10 и 12 означают условный диапазон для демонстрации синтаксиса.

```sh
python3 'Источники/поиск.py' add 'w5:43' '/путь/к/учебнику.pdf' --pages 10 12
```

Для новой темы можно добавить собственную карточку. Укажите `--course`, `--grade`, `--paragraph` и `--title`. Если название книги отличается от названия курса, передайте `--book`. Параметр `--keywords` добавляет имена и термины для поиска. Связи с локальными файлами хранятся в `локальные-источники.json`.

Если PDF состоит из сканов, извлеките нужные страницы с помощью распознавания текста и подключите результат как TXT. Для заданий по карте, таблице или иллюстрации передайте модели само изображение этих страниц.

## Работа через API

Приложение может выполнить те же операции на сервере по вызову модели. Объявите два инструмента с входными полями из `find` и `read`, затем передавайте модели только их JSON-ответы. Доступ к рабочей папке, команды и файлы должны быть на стороне приложения. Без вызова инструмента системный промпт сам по себе не открывает локальные учебники.
